# OrangeCloud Player SDK - Demos

各平台完整播放器 Demo，演示 SDK 所有功能。

## 目录

| 平台 | 目录 | 功能演示 |
|------|------|----------|
| Flutter | [flutter/](./flutter) | 基础播放、短视频、离线下载、画中画 |
| Android | [android/](./android) | Activity 集成、播放控制、事件监听 |
| iOS | [ios/](./ios) | SwiftUI 播放器、进度控制、截图 |
| Web | [web/](./web) | HLS/DASH 播放、控制栏、事件日志 |
